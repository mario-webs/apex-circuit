# Apex Circuit Grand Prix · versión web

Juego de carreras de F1 en 3D que se juega en el navegador: física de monoplaza, boxes reales, duelo 1 vs 1 en pantalla partida, guía de conducción (tecla G) y editor de circuitos.

**Jugar:** https://mario-webs.github.io/apex-circuit/

Funciona en Chrome, Edge y Firefox de escritorio, con teclado o mando.
